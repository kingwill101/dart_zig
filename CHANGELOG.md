## 0.1.0

- Generate typed Dart calls, streams, signals, and state endpoints from Zig
  handlers and message declarations.
- Run native work through sessions with worker queues, cooperative cancellation,
  deadlines, callbacks, and diagnostics.
- Manage binary attachments, owned native buffers, native handles, and cleanup.
- Use the generated session API on native Dart, Flutter, and WebAssembly.
- Initialize application Zig builds and Dart build hooks with the `dart_zig`
  command-line tool.
