# Minimal example

This standalone Dart project exports `add(i64, i64)` from Zig and calls it
through a binding generated by `native_toolchain_zig`. It has its own build hook
and native asset. It needs no `dart_zig` session or binary codec.

From this directory:

```sh
dart pub get
dart run native_toolchain_zig:zig bindings --zig-dir zig --root-source-file src/exports.zig --output lib/src/ffi.g.dart --asset-id package:minimal_example/minimal_example.dart
dart run bin/main.dart
```

The expected output is `20 + 22 = 42`. After changing the Zig export, rerun the
binding generator. The build hook compiles the example's native asset when Dart
runs it.
