# Examples

Each example has its own Dart package, Zig sources, and native build hook. Open
its README for setup and run instructions.

| Feature | Example |
| --- | --- |
| Direct FFI | [Minimal](https://github.com/kingwill101/dart_zig/tree/main/example/minimal_example) |
| Typed calls | [Calls](https://github.com/kingwill101/dart_zig/tree/main/example/calls_example) |
| Native streams | [Streams](https://github.com/kingwill101/dart_zig/tree/main/example/streams_example) |
| Signals and state | [Signals and state](https://github.com/kingwill101/dart_zig/tree/main/example/signals_state_example) |
| Binary attachments | [Attachments](https://github.com/kingwill101/dart_zig/tree/main/example/attachments_example) |
| Zig-to-Dart callbacks | [Callbacks](https://github.com/kingwill101/dart_zig/tree/main/example/callbacks_example) |
| Native handles and buffers | [Native ownership](https://github.com/kingwill101/dart_zig/tree/main/example/native_ownership_example) |
| Cleanup and restart | [Lifecycle](https://github.com/kingwill101/dart_zig/tree/main/example/lifecycle_example) |
| Logs and runtime counters | [Diagnostics](https://github.com/kingwill101/dart_zig/tree/main/example/diagnostics_example) |
| Independent isolates | [Isolates](https://github.com/kingwill101/dart_zig/tree/main/example/isolates_example) |
| In-memory transport | [Memory transport](https://github.com/kingwill101/dart_zig/tree/main/example/memory_transport_example) |
| Native-to-Dart request/reply | [Native requests](https://github.com/kingwill101/dart_zig/tree/main/example/native_requests_example) |
| Typed signal in Flutter | [StreamBuilder](https://github.com/kingwill101/dart_zig/tree/main/example/typed_signal_flutter_example) |
| Flutter native compute | [Fractal](https://github.com/kingwill101/dart_zig/tree/main/example/fractal_flutter_example) |
| Continuous Flutter updates | [Particle stream](https://github.com/kingwill101/dart_zig/tree/main/example/particle_stream_flutter_example) |
| Web and Wasm | [Web](https://github.com/kingwill101/dart_zig/tree/main/example/web_example) |

The [runtime features example](https://github.com/kingwill101/dart_zig/tree/main/example/runtime_features_example)
combines several APIs in one integration project. Start with a focused
example when learning one feature, then use it to see how the pieces work
together.
