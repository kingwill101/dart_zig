# Examples

Each example has its own Dart package, Zig sources, and native build hook.
Run commands from the example's directory so the correct package and asset are
used. The examples require Dart 3.13 or later and Zig 0.15.2 or 0.16.0; Flutter
examples also need a compatible Flutter SDK, and the Web runner needs Node.

## Start with a small project

For your first session-based call, run:

```sh
cd example/calls_example
dart pub get
dart run bin/main.dart
```

The [minimal example](https://github.com/kingwill101/dart_zig/tree/main/example/minimal_example)
shows a synchronous direct FFI call. Flutter examples use `flutter pub get`
and `flutter run`; the [Web guide](/web-and-wasm) covers its build and runner.
Open each project's README for its full setup and run instructions.

## See the features together

The [runtime features example](https://github.com/kingwill101/dart_zig/tree/main/example/runtime_features_example)
combines several APIs in one integration project. Start with a focused
example when learning one feature, then use it to see how the pieces work
together.
